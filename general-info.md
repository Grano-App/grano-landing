# Grano — Реліз додатку в стори

## Загальна інформація

- **Проєкт:** Мобільний додаток Grano — цифровий помічник для українських фермерів
- **Розробник:** Faynosoft
- **Основний бізнес компанії Grano:** продаж насіння та хімії (інтернет-магазин)
- **Додаток:** позиціонується як "цифровий помічник", а не просто інтернет-магазин
- **Імейл компанії:** granoinua@gmail.com (особистий Gmail)
- **Локалізація:** українська (uk_UA)
- **Технології:** Flutter (Dart), BLoC/Cubit, Firebase, Google Maps

## Функціональність додатку

1. **Управління полями** — облік фермерських полів, сільськогосподарських операцій, культур (Google Maps, GeoJSON полігони)
2. **Інтернет-магазин агрохімії** — каталог, кошик, оформлення замовлень (доставка, Нова Пошта, онлайн оплата)
3. **AI-діагностика рослин** — визначення хвороб по фото (в розробці, наразі заглушка)
4. **Погода** — прогноз по областях через Open-Meteo API
5. **Push-сповіщення** — Firebase Cloud Messaging (нагадування, пропозиції, оновлення)
6. **Профіль та адреси** — управління даними користувача, Google Places автозаповнення

## Відомі обмеження (технічний борг)

- AI-діагностика — лише UI-заглушка
- Кошик не зберігається між сесіями
- Темна тема заблокована (інфраструктура є)
- Google API key захардкоджений у код
- Номер замовлення генерується на клієнті (5 випадкових цифр)
- Історія замовлень без повної реалізації

## План реєстрації акаунтів

### Крок 1 — Google Workspace

- Зареєструвати Google Workspace на домені **grano.in.ua**
- Створити корпоративну пошту: **admin@grano.in.ua** (головний акаунт, менеджер Grano)
- Створити робочий акаунт розробника: **dev@grano.in.ua** (для релізів)
- Назву компанії в Workspace можна змінити пізніше в admin.google.com

### Крок 2 — Google Play Console

- Зареєструвати акаунт з **admin@grano.in.ua**
- Тип акаунту: **комерційна компанія** (назва організації відображається в сторі)
- Вартість: одноразова оплата **$25**
- Додати dev@grano.in.ua з роллю **Release Manager**

### Крок 3 — Apple Developer Program

- Створити Apple ID на **admin@grano.in.ua**
- Зареєструватись в Apple Developer Program як **Organization** ($99/рік)
- Необхідний **D-U-N-S номер** для ТОВ Грано (перевірити на dnb.com, отримання до 30 днів)
- Apple може верифікувати через дзвінок на офіційний номер компанії
- Додати dev@grano.in.ua з роллю **App Manager**

## Важливі рішення (потребують уточнення)

### Домен для додатку

Існуючі домени орієнтовані на інтернет-магазин насіння/хімії і не підходять для презентації додатку як цифрового помічника. Варіанти:

- **Піддомен:** app.grano.in.ua — безкоштовно, швидко
- **Окремий домен:** granoapp.com, grano.app, mygrano.com — повна незалежність

Потрібен лендінг для додатку: опис, скріншоти, посилання на стори, Privacy Policy, Terms of Service.

### Що потрібно для релізу в стори

- Скріншоти додатку для різних розмірів екранів
- Іконка додатку
- Опис додатку (укр/англ)
- URL політики конфіденційності (Privacy Policy)
- URL сайту розробника
- Зібрані релізні білди: AAB (Google Play), IPA (App Store)
